# OpenGen visual research

Updated 2026-11-25 (v3 finalized 2026-11-24; initial check 2026-11-03). The user requested a coherent, high-contrast palette and permitted changing every color while retaining the current design language. After rejecting an intermediate muted charcoal-pine experiment (`v2`) as too muted and low-energy, OpenGen finalized the **v3 High-Contrast Editorial Pantone 2022–2026 Color System**: a lush deep jewel emerald forest canvas, an AAA 3-tier Cloud Dancer ink ladder, restored bold solid Pantone color-blocked panels, modality-coded Aqua/Peach catalog cards, Lemon Icing tabular route prices, electric Viva Magenta primary actions matching the untouched brand mark, strictly disciplined Luminous Aqua links and site-wide typography. The **2026-11-25 v4 80s Retro-Futuristic High-Contrast Pantone Polish** preserves the complete v3 token table, AAA contrast ratios and `>= 12px` readable font scale while adding restrained 1980s hardware-instrument typography moments, whisper-quiet workstation textures, sharper `4–12px` geometric radii, tactile hard-offset shadows and pilot-lamp status glows.

## Typography stack and readability contract

All fonts are self-hosted SIL OFL-1.1 `@fontsource` packages so offline and deterministic CI builds require no runtime Google Fonts requests. License texts live in `apps/web/public/licenses/` (`plus-jakarta-sans.txt`, `inter.txt`, `jetbrains-mono.txt`, plus retained `hanken-grotesk.txt`, `dm-mono.txt` and `geist-pixel.txt` for the outlined brand SVGs and decorative marks).

- **`--heading`**: `'Plus Jakarta Sans', 'Hanken Grotesk', system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` (weights `500`, `600`, `700`). Used for Hero H1 (`clamp(2.25rem, 4.6vw, 4rem)`, `1.12`, `-0.025em`), Page H1 (`clamp(2rem, 3.8vw, 3.25rem)`, `1.15`, `-0.02em`), Section H2 (`clamp(1.5rem, 2.4vw, 2rem)`, `1.22`, `-0.015em`, except `.home-pricing h2` which uses `--display` in v4) and card/panel headings.
- **`--sans`**: `'Inter', 'Hanken Grotesk', system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` (weights `400`, `500`, `600`, `700`) with `font-feature-settings: 'cv05' 1, 'cv08' 1;` for clear `I`/`l`/`1` disambiguation. Base body is `16px / 1.6`, secondary descriptions and table cells sit at `14px–15px / 1.5–1.55`, plain UI controls/labels/table `th` headers at `13px–14px`, captions at `13px`, and all text stays at or above an absolute floor of **`12px`** (zero rules `< 12px` across desktop and mobile; mobile inputs stay `>= 16px`).
