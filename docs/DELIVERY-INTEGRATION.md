# Private delivery module handoff

2026-11-04. Fixture-backed source implementation; not live-provider, native-PostgreSQL, isolated-native-media or hosted deployment qualification.

## Implemented modules

- `delivery.ts`: private per-slot URL/owned/inline checkpoint, scope/attempt validation, deterministic immutable object key, lease/due/retry/expiry state, original-task URL refresh, bounded private inline staging and recovery. Retained objects are checked before source retry exhaustion, including a last-attempt PUT/DB crash. Known decoder failure or requested-output nonconformance is terminal unusable; its bytes stay private for audit. It has no generation-submit, reservation or settlement dependency. `result(scope)` contains only owned object metadata and delivery state; its internal URL placeholder must be signed after authorization.
- `delivery-projection.ts`: workspace authorization before signing, strict per-job object keys and media extensions, explicit customer field allowlists, no raw provider output URLs, recovery descriptors, storage keys or credential connection IDs. Signing failure removes output instead of returning an old URL. The baseline job fields are projected; integration must add any newly accepted safe attribution/progress/metadata fields from the shared C0 contract explicitly.
- `adapter-output.ts` plus OpenAI/Google image/video/Replicate constructors: optional `captureOutputs` called with all output descriptors/inline bytes before archival. Known upstream success remains success if capture/delivery fails. The legacy storage callback remains available until shared wiring opts in.
- `inspection.ts`: declarations separate from observations; isolated bounded ffprobe metadata plus separate full ffmpeg decode/frame evidence; conformance decisions/notices; checker-attributed content safety. Default safety is not checked. Missing tools are unknown. `delivery.ts` stores this inspection and existing C2PA verification together on the private receipt. No signature or Official attribution proves model origin.
- `output.ts` immediately fails closed without storage: no raw provider URL fallback.
- Compatibility handlers require available, nonempty usable output for image success/video completed/content redirect. They retain the same job for pending/partial delivery and report independent generation, delivery and charge state. Explicit delivery readiness comes from the shared trusted projection.
